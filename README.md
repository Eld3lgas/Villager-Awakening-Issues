# Villager Awakening - Issue Tracker

Welcome! This repository is dedicated to bug reports and feature suggestions for the **Villager Awakening** Minecraft mod.

### How to Report a Bug
1. Check the [Existing Issues](https://github.com/YOUR_USERNAME/villager-awakening-issues/issues) to make sure your bug hasn't already been reported.
2. Click **New Issue**.
3. Include your Minecraft version, Modloader version, and relevant crash logs or screenshots!
